Rebalanceamento e aporte sugerido para Cripto

Análise do cálculo atual para ativos como Bitcoin (BTC)

1. Onde o cálculo está

A lógica está diretamente em src/pages/RebalancerPage.jsx. Ela não é calculada pelo serviço geral de totais da carteira.

const aporte = Number(novoAporte) || 0;
const patrimonioTotal = assets.reduce(
  (total, asset) => total + getAssetValue(asset),
  0
);

const distribuicao = assets.map((asset) => {
  const valAtual = getAssetValue(asset);
  const meta = getAssetTarget(asset);
  const valorIdeal = (meta / 100) * patrimonioTotal;

  return {
    ...asset,
    valAtual,
    meta,
    valorIdeal,
    aporteSugerido: 0,
    cotasSugeridas: 0
  };
});

2. Fórmula do déficit do Bitcoin

Se P é o patrimônio atual, B é o valor atual do BTC e a meta é 15%, o código usa:

Valor ideal BTC = 0,15 × P
Déficit BTC = (0,15 × P) − B

Durante o loop, qualquer aporte já alocado também é subtraído:

const alocadoAtual = asset.valAtual + asset.aporteSugerido;
const deficit = asset.valorIdeal - alocadoAtual;

let dinheiroRestante = aporte;

if (crypto && price > 0) {

distribuicao[index].aporteSugerido += valorParaAplicar;

O campo Novo Aporte Disponível é usado somente como dinheiro disponível para aplicar e como limite da compra. Ele não entra no cálculo de valorIdeal nem no cálculo inicial do déficit.

O valor futuro exibido na tela usa patrimonioTotal + aporte, mas isso é apenas apresentação; esse total futuro não é usado para recalcular a meta.

4. Por que R$ 441,57 fica fixo

Se o patrimônio atual e o valor do BTC produzirem:

Déficit BTC = 15% × patrimônio atual − valor atual do BTC
Déficit BTC = R$ 441,57

Então qualquer aporte maior que R$ 441,57 será limitado por:

Aporte BTC = min(R$ 441,57, dinheiro disponível)

R$ 1.000,00R$ 441,57
R$ 5.000,00R$ 441,57

O valor trava porque a base P permanece constante. O novo aporte aumenta o patrimônio futuro, mas não aumenta o déficit calculado.

5. Exemplo numérico

Patrimônio atual: R$ 5.000,00
BTC atual:        R$   308,43
Meta BTC:         15%
Novo aporte:      R$ 1.000,00
Valor ideal atual = 5.000,00 × 0,15 = R$ 750,00
Déficit atual = 750,00 − 308,43 = R$ 441,57

O código aporta R$ 441,57. Depois:

BTC depois do aporte = 308,43 + 441,57 = R$ 750,00
Patrimônio futuro     = 5.000,00 + 1.000,00 = R$ 6.000,00
Percentual real BTC   = 750,00 / 6.000,00 = 12,5%

Portanto, o BTC chega a 15% do patrimônio antigo, mas não a 15% do patrimônio futuro.

6. Fórmula necessária para atingir a meta após o aporte

Para rebalancear considerando o dinheiro novo, a base deveria ser o patrimônio futuro:

Valor ideal novo = 15% × (patrimônio atual + novo aporte)
Déficit novo = [15% × (P + A)] − B

No mesmo exemplo:

Patrimônio futuro = 5.000,00 + 1.000,00 = R$ 6.000,00
BTC ideal futuro  = 6.000,00 × 0,15 = R$ 900,00
Déficit correto   = 900,00 − 308,43 = R$ 591,57

Assim, o BTC deveria receber R$ 591,57 para terminar exatamente em 15% do patrimônio após o aporte.

Conclusão

Causa do valor fixo: o algoritmo calcula o ideal com base somente no patrimônio atual. O novo aporte é tratado como caixa disponível, mas não como parte da nova base percentual. Para escalar corretamente, o cálculo precisa usar patrimonioTotal + aporte ao determinar o valor ideal.
