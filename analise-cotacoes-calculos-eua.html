Análise de Cotações e Cálculos

Ativos brasileiros versus Ações EUA, REITs EUA e ETFs EUA

1. Fluxo de atualização de cotações

O botão da tabela chama useUpdateQuotes, que encaminha cada ativo para fetchAssetData.

const incoming = await fetchAssetData(asset);

const mergedUpdates = {
  price: incoming.price ?? asset.price,
  priceOriginal: incoming.priceOriginal ?? asset.priceOriginal ?? null,
  priceCurrency: incoming.priceCurrency ?? asset.priceCurrency ?? 'BRL'
};

Ativos BR seguem para a Brapi. Ativos EUA seguem para a Alpha Vantage:

if (
  type.includes('eua') ||
  type.includes('internacional') ||
  type.includes('reit') ||
  type.includes('etf internacional') ||
  type.includes('global')
) {
  return fetchAlphaVantageData(asset.ticker, asset.moeda || 'USD');
}

return fetchBrapiAssetData(asset.ticker);

2. Por que EUA retorna “Erro ao buscar cotações”

A chamada para a Alpha Vantage é:

const params = new URLSearchParams({
  function: 'GLOBAL_QUOTE',
  symbol: String(ticker || '').trim()
});

const response = await fetch(
  `https://www.alphavantage.co/query?${params.toString()}`
);

const data = await response.json();
const quote = data?.['Global Quote'];
const originalPrice = Number(quote?.['05. price']);

O código exige a resposta Global Quote → 05. price. Quando a Alpha Vantage devolve limite excedido, chave demo, ticker inválido ou resposta informativa, essa estrutura não existe:

if (!Number.isFinite(originalPrice) || originalPrice <= 0) {
  throw new Error(
    'Alpha Vantage: dados indisponíveis ou limite de requisições atingido'
  );
}

O erro então é capturado e convertido na mensagem genérica da interface:

catch (err) {
  console.error('Update quotes error:', err);
  setUpdateMsg(t.erroCotacoes);
}
Diagnóstico: o roteamento por tipo está correto. O problema mais provável é a resposta da Alpha Vantage, a chave/limite da API ou um ticker com sufixo incompatível. A quantidade de cotas não participa do fetch.

3. Ticker e conversão cambial

O ticker é apenas removido de espaços:

symbol: String(ticker || '').trim()

O formulário costuma salvar o ticker em maiúsculas, mas a função não remove explicitamente sufixos como .US, :US ou outras extensões. Tickers simples como AAPL, MSFT e AMZN são o formato esperado.

A conversão ocorre somente depois de obter a cotação:

const rates = await fetchExchangeRates();
const rate = rates[currency.toLowerCase()];

if (Number.isFinite(rate) && rate > 0) {
  priceBrl = originalPrice * rate;
} else {
  throw new Error(`Exchange rate for ${currency} was not found`);
}

Assim, câmbio não altera o ticker. Porém, se o câmbio falhar, a atualização também termina em erro para ativos estrangeiros.

4. Cálculo de custo, valor atual e lucro

O cálculo está em src/services/calculationService.js:

const quantity = Number(item.qty) || 0;
const currentUnitPrice = Number(item.price) || 0;
const averageUnitPrice = Number(item.pm) || 0;

const valorTotal = quantity * currentUnitPrice;

const valorInvestido = isCrypto(item.type, item.ticker)
  ? averageUnitPrice
  : quantity * averageUnitPrice;

const lucro = valorTotal - valorInvestido;

Para Ações EUA, REITs EUA e ETFs EUA, o ativo não é cripto. Portanto:

Valor Atual = Quantidade × Cotação Atual unitária em BRL
Custo Total = Quantidade × Preço Médio unitário em BRL
Lucro/Prejuízo = Valor Atual − Custo Total

5. Exemplo com duas cotas

Quantidade:              2
Preço Médio unitário:   R$ 100,00
Cotação Atual unitária: R$ 120,00
Custo Total = 2 × 100 = R$ 200,00
Valor Atual = 2 × 120 = R$ 240,00
Lucro      = 240 − 200 = R$ 40,00

Com cotação atual de R$ 80,00:

Custo Total = 2 × 100 = R$ 200,00
Valor Atual = 2 × 80  = R$ 160,00
Prejuízo    = 160 − 200 = -R$ 40,00

6. Onde pode parecer haver duplicação

A tabela exibe item.pm e item.price como valores unitários, enquanto item.valorTotal já é o total:

<td>{formatMoney(item.pm)}</td>
<td>{formatMoney(item.price)}</td>
<td>{formatMoney(item.valorTotal)}</td>
<td>{formatMoney(item.lucro)}</td>

Se o campo pm for salvo incorretamente como custo total, a fórmula correta parecerá duplicar o valor:

Quantidade = 2
pm salvo incorretamente = R$ 200,00

Custo calculado = 2 × 200 = R$ 400,00

O valor correto seria salvar pm = R$ 100,00 e deixar o cálculo produzir 2 × 100 = R$ 200,00.

Conclusão: na versão atual não há inversão do sinal do lucro nem multiplicação dupla dentro da fórmula para ativos EUA. A fórmula é correta, mas depende de pm e price serem valores unitários em BRL. O erro de atualização EUA está separado do cálculo e ocorre principalmente na resposta da Alpha Vantage, no ticker aceito ou na conversão cambial.
